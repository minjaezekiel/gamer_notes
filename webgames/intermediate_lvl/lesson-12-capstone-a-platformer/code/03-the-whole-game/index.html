A browser treats every local file as its own website, so one local file may not import another. Nothing is wrong with the game. Serve the folder:

cd 03-the-whole-game
python3 -m http.server 8000

Then open http://localhost:8000. No internet is involved.

← → run · Space jump (hold for higher) · ↓ drop through a thin platform · P pause · Space on the title screen to start. Collect the coins, avoid the guards, reach the flag.
