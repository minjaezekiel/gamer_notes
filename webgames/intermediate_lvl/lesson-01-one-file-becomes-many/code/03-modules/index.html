Your browser treats every local file as its own separate website, and one website may not import another's code. Nothing is wrong with the game. Serve the folder instead:

cd 03-modules
python3 -m http.server 8000

Then open http://localhost:8000. That server runs on this computer; no internet is involved.

Arrow keys or A / D, Space to launch, R to restart. Same game as 01-one-big-file.html, same game as 02-script-tags/.
