Vectors: Two Numbers That Mean An Arrow

Used in: web L2 then web intermediate L2 · python intermediate L3 · c++ intermediate L5

A vector is just a pair of numbers, x and y. What makes it powerful is that the same pair can mean two different things: a place, or a movement. Once you can switch between those two readings, a lot of game maths stops being maths and starts being obvious.

What to look for Drag the blue and orange arrowheads. Turn on Show A + B and notice that adding vectors means putting them head to tail — walk along A, then walk along B, and the purple arrow is where you ended up. Then turn on Show the unit vector and drag A longer and shorter: the short grey arrow never changes length, only direction.

What you can do with a vector

OperationCodeIn a game, this is…

The recipe you will use constantly: chase

“Move the enemy towards the player at 120 pixels per second.” Three steps, and they are always these three steps:

// 1. SUBTRACT to get the arrow pointing from the enemy to the player
let dx = player.x - enemy.x;
let dy = player.y - enemy.y;

// 2. NORMALISE it, so we have the direction without the distance
const len = Math.hypot(dx, dy);
if (len > 0) { dx = dx / len; dy = dy / len; }

// 3. SCALE it by the speed we want, and add it on
enemy.x = enemy.x + dx * 120 * dt;
enemy.y = enemy.y + dy * 120 * dt;

Subtract, normalise, scale. Homing missiles, enemies that chase, a camera that eases towards the player, a bullet fired at the mouse — all the same three lines.

Note the if (len > 0). Without it, an enemy standing exactly on the player divides by zero and its position becomes NaN, which makes it vanish from the screen forever. That guard is not optional.

The diagonal-speed bug

Almost every first game has this bug. The player moves with the arrow keys:

if (keys.right) { player.x += 200 * dt; }
if (keys.down)  { player.y += 200 * dt; }

Hold right and down together and the player moves 200 across and 200 down. By Pythagoras, their actual speed is √(200² + 200²) ≈ 283 — about 41% faster diagonally. Players discover this within a minute and then run everywhere diagonally.

The fix is to build the movement as one vector, normalise it, and then scale by speed. Try it in the demo: drag A to point diagonally and compare its length to a straight one.

Think like an engineer

A vector of length 1 is called a unit vector, and it answers “which way?” with no information about “how far?”.

Why is throwing away the distance useful rather than wasteful? Find three places in a game where you would want the direction and specifically would not want the distance. Then find one place where throwing away the distance would be a bug.

Vocabulary
  • Vector — a pair of numbers meaning an arrow: a direction together with a length.
  • Magnitude — the length of a vector. Found with Pythagoras.
  • Unit vector — a vector whose length is exactly 1. Pure direction.
  • Normalise — to shrink or grow a vector until its length is 1.
  • Component — one of the two numbers; the x component or the y component.
