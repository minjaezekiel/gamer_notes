Which Way Do Dependencies Point?

Load order, and why a loop has no answer. Used in: web I-L1 · python A-L2 · c++ I-L3 and A-L11

When you split one file into seven, you have invented a question that did not exist before: which one is allowed to go first? There is a method for answering it, your browser runs that method every time you use import, and for some sets of files it has no answer at all.

What to look for Each press of Step 1 frame does one thing: it finds a file whose arrows all point at files that are already loaded, and loads it. Watch the order build up on the right — that is literally the order your <script> tags have to be in. Now switch on the extra arrow and step again. The method stops with files left over, and no amount of stepping will help: each survivor is waiting for one of the others. Nothing is broken. There is simply no order, and a set of files with no order is a design mistake.
