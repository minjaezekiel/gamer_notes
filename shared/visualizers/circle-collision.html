Circle Collision: Pythagoras Earns Its Keep

One comparison instead of four. Used in: web L4 · python L4 · c++ L5

Two circles are touching when the distance between their centres is less than their radii added together. That is the entire test. The only question is how to measure a diagonal distance — and the answer is a theorem you already know.

What to look for Drag either circle. The grey right-angled triangle is the one from your maths book: dx along the bottom, dy up the side, and the distance as the sloping side. Watch the two numbers at the bottom — distance and r1 + r2 — and see which is bigger.

The code

function circlesOverlap(a, b) {
  // How far apart are the centres, across and down?
  const dx = b.x - a.x;
  const dy = b.y - a.y;

  // Pythagoras: the straight-line distance between the two centres.
  const distance = Math.sqrt(dx * dx + dy * dy);

  // If the gap is smaller than the two radii added up, they must be touching.
  return distance < a.radius + b.radius;
}
The maths you just used

Pythagoras' theorem says that in a right-angled triangle, a² + b² = c², where c is the longest side.

Here, dx and dy are the two short sides, and the distance you want is the long one. Rearranged:

distance = √(dx² + dy²)

You have probably used this to find the side of a triangle in a textbook. This is the same formula doing a real job: it is how every game in the world measures “how far away is that?” It is also what Math.hypot(dx, dy) does for you in one call.

A professional trick: skip the square root

Square roots are one of the slower things a computer does. And notice: if distance < limit, then distance² < limit² as well. Both sides are positive, so squaring both keeps the answer the same. So you can write:

const distanceSquared = dx * dx + dy * dy;
const limit = a.radius + b.radius;
return distanceSquared < limit * limit;    // same answer, no square root

Tick the box in the demo to watch both versions agree on every single position. For two circles nobody would notice the difference — but for ten thousand particles, it is real. The general lesson is worth more than the trick: if you only need to compare two things, you often do not need to fully calculate either of them.

Think like an engineer

Circles need one comparison. Boxes need four. Circles do not care about rotation, boxes do. So why does almost every 2D game use boxes for most things?

Think about what shape a person, a crate, a platform and a bullet each really are. Then think about a game where the player is drawn as a person but their hitbox is a circle at their feet. What would that feel like to play? Where have you seen it?

Vocabulary
  • Radius — the distance from the centre of a circle to its edge. Half the width.
  • Euclidean distance — the ordinary straight-line distance. The Pythagoras one.
  • Squared distance — the distance before you take the square root. Used for comparisons.
  • Hitbox / hurtbox — the shape used for collisions, which need not match the drawn picture.
