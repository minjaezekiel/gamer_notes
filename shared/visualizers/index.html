Visualizer Gallery

Nine animated explainers. Open this page at the start of class and project from here.

These explainers are language-neutral. The game loop, delta time and collision are the same ideas in JavaScript, Python and C++, so there is one explainer each and all three tracks link to it. Whichever language your class is coding in today, you project from this page.

How to drive these in class
  • Click the widget once, then use the keyboard from anywhere in the room: Space plays and pauses, → steps one frame, R resets. A presenter remote usually sends those keys, so you can walk around.
  • Always step before you play. Students who watch it animate first see a pretty picture. Students who step through it frame by frame see a mechanism.
  • Ask a student to predict what the next frame will look like, then press Step. Being wrong once is worth more than ten minutes of explanation.
  • These work with the Wi-Fi switched off. Nothing loads from the internet.
  • Light or dark is remembered per machine with the button in the top-right corner. Dark usually projects better in a bright room.

In teaching order

  • 1. The Game Loop

    Input, update, render, repeat. One Step press does one job, so three presses make a frame. The foundation everything else sits on.

    web L1 · python L1 · c++ L1

  • 2. Screen Coordinates

    Y points down. Two grids side by side, one draggable dot, and the moment a student sees one number rise while the other falls.

    web L2 · python L2 · c++ L3

  • 3. Delta Time

    Two balls race at the same intended speed. Drag the frame rate to 20 and one of them falls apart. The best five seconds in the whole course.

    web L2 · python L3 · c++ L3

  • 4. Gravity, Velocity, Position

    A chain of two additions, with a live table of the numbers. Shows why a jump needs no jump code at all.

    web L2 and L6 · python L5 · c++ L5

  • 5. Vectors

    Drag two arrows, add them head to tail, and shrink one to length 1. Includes the subtract-normalise-scale recipe behind every chasing enemy.

    web L2 (lightly) · all intermediate tracks

  • 6. Box Collision (AABB)

    Four conditions, each with its own light. Students hunt for the position where exactly one is red, which is the bug they would otherwise ship.

    web L4 · python L4 · c++ L4

  • 7. Circle Collision

    Pythagoras doing a real job, with the right-angled triangle drawn on screen. Includes the skip-the-square-root trick.

    web L4 · python L4 · c++ L5

  • 8. Game States

    Clickable menu / playing / paused / game over. The lesson lands when a press gets ignored and the class realises that is correct.

    web L5 · python L6 · c++ L6

  • 9. Grids and Flat Arrays

    A grid is really one long line. Colour-banded strip plus the two formulas, y*WIDTH+x and its reverse.

    c++ L3 and L4 · python L4 · web L6

If a visualizer will not open

These are plain files, so they need no server — double-clicking works. If a widget appears but stays blank, the page cannot see ../js/anim.js, which means the shared/ folder was moved or the file was copied out of the repository on its own. Keep the folder structure intact and it will work.
