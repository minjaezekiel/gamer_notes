A Grid Is Really One Long Line

The two formulas that turn a level into memory. Used in: c++ L3 and L4 · python L4 · web L6

Computer memory has no idea what a grid is. It is one long row of boxes, numbered from zero. So every tile map, every chess board and every ASCII screen is really a single line of numbers that we agree to read in rows.

What to look for Drag the marker around the grid. Watch the matching cell light up in the long strip underneath, and watch the formula at the bottom fill in with real numbers. Notice what happens when you move one square right (the index goes up by 1) versus one square down (it jumps by a whole row’s worth).

The two formulas

Grid → index (you know x and y, you want the position in the array)

index = y * WIDTH + x;

Read it as: “skip y whole rows, then count x more across”. Each whole row you skip is WIDTH boxes long, so skipping y rows means skipping y × WIDTH boxes.

Index → grid (you know the position in the array, you want x and y)

x = index % WIDTH;              // the remainder
y = Math.floor(index / WIDTH);  // the whole part

This is long division. index ÷ WIDTH tells you how many complete rows fit, which is y. The leftover is how far across you are, which is x.

The maths you just used

The % symbol is the modulo operator, and it means “the remainder after dividing”. If WIDTH is 8, then 19 % 8 is 3, because 8 goes into 19 twice with 3 left over.

You already know this operation: it is exactly what you did in primary school as “17 divided by 5 is 3 remainder 2”. Programmers split that one answer into two operators: / (or integer division) gives the 3, and % gives the 2.

Modulo is also how you make anything wrap around — a clock face, a cycling colour, an enemy patrolling a loop of waypoints. Any time you want numbers to count up and then start again, reach for %.

Why not just use a grid of grids?

You can, and in JavaScript and Python it is often the friendlier choice:

level = [
    [1, 1, 1, 1, 1],
    [1, 0, 0, 0, 1],
    [1, 0, 2, 0, 1],
    [1, 1, 1, 1, 1],
]
tile = level[y][x]        # note: y FIRST, then x

That reads nicely, and you should use it when it does. But you still need the flat version, for three reasons. It is faster, because all the numbers sit next to each other in memory instead of being scattered. It is how files and images store pixels, so you will meet it the moment you load a level or a sprite. And in C++ a flat array is often simply easier than a two-dimensional one.

Notice the trap in the code above: it is level[y][x], not level[x][y]. The outer list holds rows, so the first index chooses which row — which is y. Getting this backwards produces a level that looks mirrored along the diagonal, and it is one of the most common bugs in a first tile-map.

Find the bug

A student’s ASCII dungeon prints correctly, but walking right eventually teleports the player to the start of the next row down, as if the screen wrapped around:

if (key == 'd') {
    player_index = player_index + 1;   // move right
}

Explain exactly why this happens, and write the check that prevents it. (Then notice: the same bug cannot happen if you store x and y separately. What does that tell you about choosing a representation?)

Think like an engineer

You now have two ways to store a 2D world: a flat array with formulas, or a list of lists. Invent a third way that would be better for a mostly-empty world — imagine a 1000×1000 map with only 40 walls on it.

Hint: you do not have to store the empty space at all. What would you store instead, and what would get harder? Whatever you invent has a name and is used in real games.

Vocabulary
  • Index — a position in an array, counted from zero.
  • Modulo (%) — the remainder after a division.
  • Row-major order — the agreement that a grid is stored one row after another. (Storing it column by column is column-major, and some maths software does exactly that, which causes no end of confusion.)
  • Stride — how far you jump in the array to move down one row. Here it is just WIDTH.
  • Tile map — a level built out of a grid of repeated square pictures.
