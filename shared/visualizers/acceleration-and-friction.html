Acceleration, Friction and Drag

Where “feel” actually lives. Used in: web I-L3 · python I-L3 · c++ I-L5

In the beginner lessons you set a speed directly: press right, move right. That is the right place to start and the wrong place to stop, because every game whose movement people describe as “feeling good” does something slightly different. It changes the speed of the change and then takes a bit of it back every frame.

What to look for Drag the orange target. The ship does not go to it; the ship accelerates towards it, which is why it overshoots and swings back. Now set friction to 0 and drag the target — the ship orbits forever and never settles, like something in space, because nothing is taking energy out. Turn friction up and the same code feels like a car. The code never changed: three numbers did.
