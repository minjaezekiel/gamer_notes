Box Collision, One Condition at a Time

Four comparisons, all of which must be true. Used in: web L4 · python L4 · c++ L4

Checking whether two rectangles overlap is the most common question in all of 2D game programming. The answer is four comparisons joined by and. The hard part is not the code — it is believing that four is exactly the right number.

What to look for Drag the orange box around. Each of the four conditions on the right turns green on its own. The boxes only count as touching when all four are green at once. Try to find a position where three are green and one is red — that is the case your game gets wrong if you forget a condition.

The code, and why each line is there

// A box is four numbers: a top-left corner, plus a width and a height.
// "AABB" stands for Axis-Aligned Bounding Box. "Axis-aligned" means the box is
// never rotated - its sides are always parallel to the screen edges. That
// restriction is what makes the test so cheap.

function boxesOverlap(a, b) {
  return (
    a.x < b.x + b.w &&   // 1. a's LEFT edge is left of b's RIGHT edge
    a.x + a.w > b.x &&   // 2. a's RIGHT edge is right of b's LEFT edge
    a.y < b.y + b.h &&   // 3. a's TOP edge is above b's BOTTOM edge
    a.y + a.h > b.y      // 4. a's BOTTOM edge is below b's TOP edge
  );
}
The trick for remembering it

Do not try to work out when two boxes do overlap. That has lots of cases: one inside the other, corner clipping corner, one wider than the other.

Instead ask the opposite question: when is it obvious they cannot possibly touch? There are only four ways to be certain — a is entirely left of b, entirely right of b, entirely above b, or entirely below b. If none of those four escape routes is true, they must be overlapping. The four conditions above are just those four escape routes, flipped around.

Turning a hard question into its easy opposite is a technique you will reuse constantly.

Find the bug

A student’s ball passes through the paddle about one time in five, always when moving fast. Their collision code is correct. What is wrong, and why does it only happen at speed?

(Hint: the test asks “are they overlapping right now?” What if, between one frame and the next, the ball was never in the paddle at all?)

Think like an engineer

This test is cheap, but a game with 500 bullets and 200 enemies would need 100,000 of these checks every single frame.

Without looking anything up, invent a way to avoid most of those checks. You are allowed to change how the objects are stored. Hint: if you knew that a bullet was in the top-left part of the screen, which enemies could you skip without even testing?

Whatever you come up with has a real name and is used in every engine. You will meet it in the advanced level — but invent it first.

Vocabulary
  • AABB — Axis-Aligned Bounding Box. A rectangle that is never rotated.
  • Overlap test — code that answers “are these two shapes in the same place?”
  • Hitbox — the invisible box used for collisions, which is often smaller than the drawn picture to make a game feel fairer.
  • Broad phase — a quick first pass that throws out pairs which obviously cannot touch.
