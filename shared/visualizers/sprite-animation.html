Spritesheets and Animation

One image, one moving rectangle. Used in: web I-L4 · python I-L5 · c++ I-L7

A walking character is not many images. It is one image with the poses laid out in a row, plus a rectangle that says which part of it to copy. Moving that rectangle along is the entire animation system.

What to look for Two clocks are running and they are not the same clock. Press Step 1 frame repeatedly. The game advances one frame every press, but the sprite only changes pose when the timer bar at the bottom fills up. Several game frames pass per sprite frame — and that is deliberate. Then switch on “advance every game frame” and watch the character vibrate instead of walk.
